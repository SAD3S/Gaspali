## Installer sur Android

1. Télécharge le fichier **`gaspalli-….apk`** ci-dessous depuis ton téléphone.
2. Ouvre-le. Android demande d'autoriser l'installation depuis ton navigateur : accepte (une seule fois).
3. Les versions suivantes s'installent **par-dessus** (tes données sont conservées).

> Version de test pour téléphones Android 64 bits (arm64). Les données restent sur le téléphone : il n'y a pas encore de compte ni de synchronisation.

## À tester

- **Scan** : bouton central → vise un code-barres (Open Food Facts), mode rafale, lampe torche.
- **Lire la date** dans la feuille d'ajout : photo de la date imprimée → confirmation.
  Au tout premier usage, Android peut mettre quelques secondes à télécharger le module de lecture.
- **Inventaire** : glisser à droite = consommé, à gauche = jeté (avec « Annuler »).
- **Fiche produit** : entamé, « J'en ai utilisé une partie », passage au congélateur.
- **Ajout sans code-barres** : bouton « + » de l'inventaire.
